# Windows: артефакты после переключения CheckBox

## Симптом

В Crescent на Windows после клика по CheckBox его отрисовка или отрисовка
соседних контролов могла оставаться повреждённой. Артефакты появлялись не
обязательно сразу: они могли проявиться после задержки и исчезнуть после
движения указателя или последующей перерисовки.

## Исправление

Проблема исправляется в Win32 backend библиотеки goWidgets, а не отдельной
перерисовкой из Crescent. Backend синхронно перерисовывает CheckBox при
обработке переключения и дерево дочерних контролов после изменения layout.
Регрессионный тест на Windows сохраняет кадр после клика и повторный кадр после
задержки без движения мыши, затем сравнивает пиксели индикатора.

Изменение отправлено в [unxed/goWidgets PR #2](https://github.com/unxed/goWidgets/pull/2)
(`Win32: repaint child controls on first show`). На момент этой записи PR открыт.
Crescent использует версию goWidgets с этим исправлением.
